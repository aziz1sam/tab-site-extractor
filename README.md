# مستخرج المواقع — فاصل التبويبات حسب الموقع

إضافة خفيفة لمتصفحات كروميوم (**Chrome**، **Edge**، **Brave**، **Opera**) مبنية وفق معيار **Manifest V3** دون أي مكتبات خارجية. تعرض التبويبات المفتوحة مجمّعة حسب الموقع بواجهة عربية (`RTL`) تدعم الوضعين الفاتح والداكن، وتتيح استخراج المواقع أو التبويبات المختارة إلى نافذة مستقلة مع ترتيبها تلقائياً، أو إغلاقها بأمان.

---

## المزايا الرئيسية

* **تصميم مدمج وأنيق مع وضعَي عرض (`قائمة | بلاطات`):**
  * **عرض القائمة (الافتراضي):** صفوف مدمجة مع أيقونات المواقع (أو أيقونة حرفية ملونة عند غياب `favicon`)، وتوسيع كل موقع لاستعراض أو استبعاد تبويبات فردية، ودعم حالة التحديد الجزئي (`indeterminate`).
  * **عرض البلاطات:** شبكة بطاقات تبرز عدد تبويبات كل موقع وتتيح تحديد الموقع كاملاً بنقرة واحدة.
* **معاينة حيّة للنافذة الجديدة:** شريط معاينة مصغّر يظهر فوق أزرار الإجراء عند تحديد أي تبويب، ليعرض ترتيب تبويبات النافذة الجديدة (**المثبّتة أولاً** ثم تبويبات كل موقع متجاورة) قبل التنفيذ.
* **البحث أولاً واختصارات لوحة المفاتيح:** تركيز تلقائي على مربع البحث فور فتح الإضافة، مع اختصار **`Enter`** للاستخراج و**`Del`** للإغلاق (عبر التأكيد المضمّن).
* **تبديل النطاق والتجميع:**
  * التبديل بين **النافذة الحالية** و**جميع النوافذ** العادية المفتوحة (مع ترقيم النوافذ ووسم النافذة الحالية).
  * التبديل بين **النطاق الرئيسي** (مثل `google.com` و`bbc.co.uk` و`user.github.io`) و**النطاق الفرعي** (مثل `mail.google.com` و`drive.google.com`).
* **تصنيف صفحات المتصفح:** جمع صفحات النظام والإعدادات والملفات المحلية (`chrome://`، `edge://`، `file://`، `about:`...) تحت بند **«صفحات المتصفح والنظام»**.
* **استخراج موثوق عبر الخلفية (`Service Worker`):**
  * إنشاء نافذة جديدة دون تبويب فارغ إضافي، وترتيب التبويبات وإعادة تثبيت المثبّتة بالتسلسل حتى لو أُغلقت نافذة الإضافة.
* **إغلاق آمن بتأكيد مضمّن:** تأكيد على الزر نفسه خلال 4 ثوانٍ، مع تنبيه مسبق إذا كان الإجراء سيغلق نافذة كاملة، والتذكير بإمكانية الاستعادة عبر `Ctrl+Shift+T`.

## خطوات التثبيت والتشغيل

1. افتح صفحة الإضافات في متصفحك:
   * **Chrome:** `chrome://extensions`
   * **Edge:** `edge://extensions`
   * **Brave:** `brave://extensions`
   * **Opera:** `opera://extensions`
2. فعّل خيار **وضع المطور (Developer mode)** من أعلى الصفحة.
3. اضغط على **تحميل إضافة غير مضغوطة (Load unpacked)** واختر مجلد المشروع.
4. ثبّت أيقونة الإضافة بجانب شريط العنوان من قائمة الإضافات لسهولة الوصول (أو استخدم الاختصار `Alt+Shift+E`).

## ملاحظات وحدود معروفة

* **مجموعات التبويبات (Tab Groups):** عند نقل التبويبات من نافذة إلى نافذة جديدة عبر واجهة المتصفح، لا ينقل كروميوم مجموعات التبويبات معها وتُفقد أثناء النقل.
* **التصفح الخفي (Incognito):** تبويبات النوافذ الخفية لا تظهر في الإضافة افتراضياً، كما يمنع المتصفح نقل التبويبات بين النوافذ العادية والنوافذ الخفية.
* **متصفح Opera:** الميزات الخاصة بـ Opera مثل **Workspaces (مساحات العمل)** قد تتصرف بشكل مختلف عند نقل التبويبات بين النوافذ، لذا يُنصح باختبارها على حدة إذا كنت تعتمد عليها بكثرة.
* **استعادة التبويبات المغلقة:** في حال إغلاق تبويبات أو نافذة بالخطأ، يمكنك استعادتها فوراً عبر اختصار المتصفح `Ctrl+Shift+T`.

## التحقق والاختبار

لفحص صحة الصياغة وتشغيل اختبارات منطق النطاقات عبر Node.js:

```bash
node --check domain-utils.js
node --check background.js
node --check popup.js
node tests/domain-utils.test.js
```
